Submundo

Projeto de jogo de simulação e estratégia em que o usuário acompanha a evolução de um personagem dentro de uma cidade com diferentes atividades e possibilidades de decisão. A experiência combina missões, negócios, territórios e mecanismos de progressão para criar objetivos de curto e longo prazo. O desenvolvimento explora a organização de sistemas de jogo, a apresentação de informações e a construção de uma interface coerente com sua ambientação. Seu foco é oferecer uma experiência interativa com identidade própria.
